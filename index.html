Alur Kerja
1. Import analytics
Export data per konten dari TikTok Analytics → import. Master Produk otomatis terupdate.
2. Generate isi konten di Master Produk
Tiap produk bisa punya 3 variasi isi konten (AI-generated). Ini yang dipakai di tiap slot jadwal.
3. Generate Jadwal
Produk auto-assign ke slot. Klik baris jadwal untuk expand script siap rekam dengan hook + isi + proof + CTA.
4. Eksekusi berurutan
Buat semua konten dalam 1 sesi sesuai urutan jadwal. Script sudah ready di tiap slot.
Dual Scoring System
MODE 1 — Benchmark (frekuensi-based SAW) Aktif saat analisa top affiliator atau data CTR/CTOR <3 produk Score = (n_upload/max × 50%) + (spread_hari/max × 25%) + (punya_label × 15%) + (max_views/max × 10%) MODE 2 — Personal (TOPSIS multi-kriteria) Aktif otomatis saat ≥3 produk punya data CTR/CTOR Bobot: CTOR 35% · CTR 25% · Sold 20% · GMV 12% · Upload 8% Steps: normalisasi → bobot → jarak ke ideal+ dan ideal− Score = d(ideal−) ÷ (d(ideal+) + d(ideal−)) → range 0–1 Klasifikasi (TOPSIS mode): WINNING TOPSIS ≥ 0.65 ATAU sold ≥ 3 + TOPSIS ≥ 0.30 POTENTIALTOPSIS ≥ 0.30 ATAU CTR > 0.5% + n ≥ 2 MONITOR Data masih minim, belum bisa dinilai DROP n ≥ 3, views < 2000, CTR = 0, no sales Anomaly Detection (otomatis): ⚡ Views spike + CTOR rendah + 1× upload → GMV Max signal 🔥 CTOR tinggi + upload sedikit → hidden winner 💰 3+ produk GMV aktif → cluster seller iklan
